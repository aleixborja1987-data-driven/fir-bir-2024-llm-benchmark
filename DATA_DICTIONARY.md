# Data dictionary

## `data/official_200_scored_items.csv` and `all_210_responses_rescored.csv`

One row per model × examination × workflow × replicate × question. The scored file has 9,600 rows; the all-position file has 10,080.

| Field | Meaning |
|---|---|
| condition_id | Stable ID linking the data to config/run_manifest.json. |
| model / model_requested / model_returned | Publication label, configured API identifier, and identifier reported in a response (where logged). |
| exam / strategy / replicate | BIR or FIR; item-wise or whole-exam; replicate 1 or 2. |
| question_number | Original booklet number, 1–210; not the index in the final scored set. |
| raw_answer_value | Exact emitted answer-field value before normalization. |
| initial_parsed_answer | Original logged extraction (or whole-exam answer field); may be empty. |
| rescored_answer / model_answer | Final selected answer after the documented extraction/reclassification rule. No correct answer is used to select it. |
| recode_rule | as_emitted, unique_answer_recovery, multiple_options_to_blank or missing_or_invalid. |
| raw_file / raw_line | Relative path to sanitized raw JSONL and 1-based original line number. |
| output_sha256 | SHA-256 of the emitted output text used by this adapter (canonical serialization for tool-input objects). Not the complete JSONL-file hash. |
| rationale | Rationale returned by the model, when supplied; not manually inferred. |
| correct_answer | Reference choice in supplied answer-key CSV. |
| has_official_answer | Supplied key has an evaluable reference answer. |
| has_image | Image-containing status in supplied questions CSV, not evidence the endpoint received an image. |
| included_in_official_200 | Selection generated by the supplied first-200-valid-items algorithm. |
| official200_position | Position 1–200 in the selected set. |
| selection_reason | scored_main, used_reserve, unused_reserve or no_answer_in_supplied_key. |
| rescored_status | correct, incorrect, blank, missing_or_invalid or not_evaluable. |
| is_correct / is_blank | Boolean final-scoring indicators. Blank counts include recoded multiple choices. |
| score | +1 correct, -1/3 incorrect, 0 blank/missing; missing for unkeyed items. |

## Audit files

`reclassification_audit_scored.csv`: 54 scored cases, with original emitted text, initial and final answers, rule, source pointer, correctness and score. `reclassification_audit_all.csv`: the same plus unused reserve Q210. The latter is not counted among the 43 scored recoveries.

## Request records and run manifest

`request_records.csv` is **not an answer-level table**. Whole-exam requests yield 210 answers per record; item-wise records can represent retained requests or failed attempts. `is_final_record` indicates whether a record supplied the retained answers. Attempt counters may summarize additional attempts whose complete responses are not present. `run_manifest.csv` gives per-condition scope and minimum observed attempt totals.

Latency fields distinguish final-attempt durations, original logged durations and retry-inclusive time. Missing values mean not recorded/not consistently available, not zero. Cache tokens are not added to already inclusive totals. Reasoning tokens are a component, not an additional independent count to add to total_tokens.

## Tables and uncertainty

Condition means average two complete runs. Bootstrap interval bounds come from resampling original question clusters with both replicates retained. n_items is 200, 180 or 20 as labelled. Scores are on the scale of that subset. Descriptive agreement has no accompanying superiority test. Estimated cost uses the documented input/output rates without cache discounts.

## Provenance

`source_inventory.csv` maps selected original research sources to public package paths and hashes. Redactions are listed separately without disclosing the removed credentials or identifiers. `SHA256SUMS.txt` verifies the distributed files; regenerated SVG metadata or files can change checksums after rerunning. Source hashes remain the integrity reference for deposited evidence.
